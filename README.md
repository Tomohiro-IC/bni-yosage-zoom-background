# BNI よさげチャプター Zoom背景画像生成ツール

BNI 第２６期 よさげチャプターのメンバー向けに、プロフェッショナルなZoom背景画像を簡単に作成できるWebアプリケーションです。

## 🎯 主な機能

### ✅ 完成済み機能

1. **個人情報入力**
   - お名前（必須、最大20文字）
   - ビジネスカテゴリ（必須、最大30文字）
   - 役職／役割（任意、最大20文字）

2. **画像アップロード機能**
   - ドラッグ&ドロップ対応
   - JPG、PNG、GIF形式サポート
   - 最大ファイルサイズ：5MB
   - リアルタイムプレビュー表示
   - 縦横比保持フィット表示（600px×600px）

3. **背景画像生成**
   - 1920×1080pxの高解像度出力
   - BNIブランドカラー準拠
   - BNI・BNAIロゴの自動配置
   - 個人画像の自動レイアウト調整

4. **ダウンロード機能**
   - PNG形式での高画質出力
   - 自動ファイル名生成（日付・個人情報含む）
   - ワンクリックダウンロード

## 📐 レイアウト仕様

- **キャンバスサイズ**: 1920×1080px (16:9)
- **個人画像**: 右側配置、600×600px枠内にフィット
- **お名前**: 右上配置、72px太字、BNIダークブルー
- **ビジネスカテゴリ**: お名前の下、54px太字、グレー
- **役職／役割**: 上部中央、72px太字、BNIレッド
- **BNIロゴ**: 左上配置、280px
- **BNAIロゴ**: 左中央配置、480px幅
- **アクセント**: 下部BNIレッド帯、装飾ライン

## 🚀 使用方法

1. **情報入力**
   - お名前とビジネスカテゴリを入力（必須）
   - 役職／役割を入力（任意）

2. **画像アップロード**
   - 個人画像を選択またはドラッグ&ドロップ（任意）
   - 対応形式：JPG、PNG、GIF

3. **背景生成**
   - 「背景画像を生成」ボタンをクリック
   - プレビューで確認

4. **ダウンロード**
   - 「画像をダウンロード」ボタンでPNG形式保存

## 🎨 デザインコンセプト

- **BNIブランド準拠**: 公式カラーとロゴを使用
- **プロフェッショナル**: ビジネス用途に適したデザイン
- **ユーザビリティ**: 直感的で使いやすいインターフェース
- **レスポンシブ**: デバイスを問わず快適に利用可能

## 🔧 開発者向け情報

### 主要クラス
- `BNIBackgroundGenerator`: メインアプリケーションクラス

### 設定値
- `config.colors`: BNIブランドカラー
- `config.fonts`: フォント設定
- `config.layout`: レイアウト座標・サイズ

### 主要メソッド
- `generateBackground()`: 背景画像生成
- `drawFittedImage()`: 画像フィット描画
- `downloadImage()`: ダウンロード処理
